# C Queue Implementation

This repository contains a simple program written in C that demonstrates the First-In, First-Out (FIFO) Queue data structure using dynamic memory allocation (linked lists). 

This project was created to help understand how to manage `head` and `tail` pointers in a dynamic data structure using `malloc` and `free`.

## Features

* **Enqueue:** Add a new character to the back (tail) of the queue.
* **Dequeue:** Remove and return the character from the front (head) of the queue.
* **Print:** Display all current elements waiting in the queue.

## Getting Started

### Prerequisites

You will need a C compiler (like GCC) installed on your system to compile and run this program.

### Compilation

Open your terminal, navigate to the directory containing your code (e.g., `queue.c`), and run the following command to compile it:

```bash
gcc -o queue_program queue.c
```

### Execution

Run the compiled executable using:

```bash
./queue_program
```

Follow the on-screen instructions or modify the `main` function in the source code to test different enqueue and dequeue operations.
